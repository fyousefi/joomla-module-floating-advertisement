# Floating Advertising Module

Site module for Joomla 3.10 and Joomla 4+. Shows a fixed advertisement bar at the bottom of the page, from either an image/link or a third-party script.

## Requirements

- Joomla 3.10 or 4.x / 5.x
- PHP 5.6+ (Joomla 3) or the PHP version required by your Joomla 4/5 site

## Install

Install `mod_floating_advertising_2.0.0.zip` from **Extensions → Manage → Install**. Then create a site module instance, choose a position that is rendered on all pages, and publish it.
